# Mobile POS & ERP

A modern Mobile Shop POS & ERP System built with Next.js, NestJS, Prisma and PostgreSQL.

## Features

- Multi-Branch Management
- Inventory Management
- IMEI Tracking
- POS Terminal
- Customer Management
- Sales & Returns
- Finance & Reports
- Role Based Access
- Dashboard Analytics

## Tech Stack

- Next.js
- NestJS
- TypeScript
- Prisma ORM
- PostgreSQL
- Tailwind CSS
